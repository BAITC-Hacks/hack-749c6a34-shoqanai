# AI Sana Challenge Hub

Начальная версия проекта команды **ShoqanAI** для образовательного трека **HackAlemAI**.

## Идея

Помочь бизнесу превратить короткое описание проблемы в понятную задачу для студенческих команд. Бизнес уточняет условия, студенты предлагают решения, а выбор команды остаётся за бизнесом.

## Что уже есть

- Адаптивная главная страница на русском языке.
- Описание ценности проекта для бизнеса и студентов.
- Форма идеи: название и описание проблемы.
- Проверка заполнения и сохранение черновика в localStorage.
- Восстановление черновика при следующем открытии.

Это **старт проекта, а не готовый MVP для сдачи**. Настоящий AI, рейтинг задач, каталог, отклики и сервер пока не реализованы. Страница явно сообщает об этом пользователю.

## Стек

HTML, CSS, JavaScript. Без фреймворков и внешних зависимостей.

## Запуск

Откройте `index.html` в браузере. Для предсказуемой работы localStorage удобнее использовать локальный сервер:

```sh
python -m http.server 8000
```

Откройте http://localhost:8000. Команду нужно запускать из папки с этим README.

## Структура

```text
index.html    Главная страница и форма
style.css     Оформление и адаптивность
app.js        Валидация и сохранение идеи
.gitignore    Исключения для Git
README.md     Описание и план проекта
```

## Загрузка на GitHub

В существующем репозитории: **Add file → Upload files**. Загрузите содержимое этой папки, чтобы `index.html` и `README.md` оказались в корне репозитория, затем создайте коммит с сообщением `Add AI Sana starter website`.

Если Git уже настроен, скопируйте файлы в локальную папку нужного репозитория и выполните:

```sh
git add index.html style.css app.js README.md .gitignore
git commit -m "Add AI Sana starter website"
git push
```

Не помещайте в репозиторий API-ключи и персональные данные. Черновик хранится только в текущем браузере и не отправляется на сервер.
